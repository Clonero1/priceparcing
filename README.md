# Монитор цен по артикулам

CLI-агент открывает `impart.online` и `autopiter.ru` в Chromium, выполняет поиск по паре `артикул + производитель`, извлекает предложения в рублях и сохраняет историю. При следующем запуске он показывает изменение минимальной цены.

## Простой запуск в Windows

1. Полностью распакуйте переносимый ZIP.
2. Положите в папку агента свежий `Файл обмена XLSX.xlsx` и отчёт `Возраст товаров CAT по FIFO...xlsx`.
3. Один раз выполните `НАСТРОИТЬ ПОЧТУ.cmd`.
4. Дважды щёлкните `СБОР ЦЕН.cmd`. Окно закроется, а сбор продолжится в фоне.
5. Дважды щёлкните `СТАТУС.cmd`, чтобы открыть живой экран прогресса.

При первом запуске `СБОР ЦЕН.cmd` сам откроет ImPart и Autopiter для входа в личные кабинеты. После входа вернитесь в служебное окно и нажмите Enter. Повторно выполнять авторизацию при каждом сборе не нужно.

Перед каждым сбором программа автоматически проверяет опубликованную версию в ветке `main` репозитория GitHub и при наличии новой версии обновляет себя в текущей папке. Авторизация, история, настройки почты, XLSX и папка `Отчёты` сохраняются. Для ручной проверки обновлений используйте `ОБНОВИТЬ.cmd`. Если интернет или GitHub временно недоступны, запускается установленная версия.

`СТАТУС.cmd` обновляется каждые 5 секунд и показывает текущий артикул, количество завершённых позиций, среднюю скорость, прошедшее и оставшееся время и ориентировочное завершение по времени Екатеринбурга. После первых 10–20 позиций прогноз становится точнее. Закрытие окна статуса не останавливает сбор.

Сбор всего прайса Caterpillar работает скрыто. Каждая готовая позиция сразу сохраняется. Для остановки используйте `ОСТАНОВИТЬ.cmd`.

Фоновый сбор использует две параллельные позиции и паузу 6 секунд между пакетами. Для 2881 позиции расчётное время составляет около 4–5 часов при штатной работе сайтов. CAPTCHA, ограничения площадок и ручное устранение сбоев увеличивают итоговое время.

Если во время скрытого сбора сайт запросит CAPTCHA, агент сам откроет видимое окно браузера. Пройдите проверку и при необходимости войдите в личный кабинет. После исчезновения CAPTCHA и подтверждения входа окно закроется автоматически, сохранит новую сессию и повторит запрос.

При любой другой технической ошибке сбор полностью приостанавливается на текущем артикуле. Агент показывает предупреждение Windows и открывает проблемный сайт. После устранения ошибки нажмите `OK`: программа заново проверит ImPart и Autopiter. К следующему артикулу она перейдёт только после штатного ответа обоих сайтов. Отсутствие конкурентного предложения считается штатным ответом.

После завершения агент создаёт папку `Отчёты` и сохраняет туда Excel со сверкой цен, возрастом FIFO, себестоимостью, регламентной ценой и аналитикой. Возраст рассчитывается заново в днях на дату запуска. Если настроен классический Outlook для Windows, Excel автоматически отправляется на сохранённый адрес вместе с краткой аналитикой в тексте письма.

Если почта была настроена уже после завершения сбора, запустите `ОТПРАВИТЬ ПОСЛЕДНИЙ ОТЧЁТ.cmd`. Программа найдёт самый свежий Excel в папке `Отчёты` и отправит его без повторного сбора цен.

Цены ImPart и Autopiter в отчёте приводятся без 20% наценки площадок. На Autopiter агент сначала открывает карточку нужного производителя, затем исключает карточки с кодом `RS`, цены, совпадающие с нашей после снятия наценки, и строки с пометками «АНАЛОГ», `World Gasket` или `(WG)`. На ImPart исключаются предложения из Екатеринбурга.

Для расчёта колонки «Регламентная цена» агент выбирает меньшую из очищенных цен ImPart и Autopiter. Затем применяет возрастную наценку к себестоимости и минимальный рыночный предел из регламента. Если себестоимость или цена по возрасту выше рынка, значение сохраняется для анализа и выделяется жёлтым: такая позиция требует ручного согласования по регламенту.

## Запуск

Требуются Node.js 20+ и Chromium. На сервере агент использует `/usr/bin/chromium`; на обычном компьютере установите браузер Playwright одной командой:

```bash
npm install
npx playwright install chromium
npm run monitor -- 3687816
```

Если сайты блокируют адрес дата-центра, запускайте агент на своём компьютере через домашний или офисный интернет. Первый запуск выполните с видимым браузером:

```bash
npm run monitor -- 3687816 --headed
```

Cookies и `localStorage` каждого сайта сохраняются в `.data/browser-state`, поэтому подтверждённая браузерная сессия используется при следующих запусках. Эти файлы локальные и исключены из Git.

Агент читает XLSX, CSV и TXT. Для пилота обрабатываются только строки с брендом `Caterpillar`; на сайтах бренд `CAT` считается тем же производителем, а `CTP` остаётся отдельным брендом.

```bash
npm run monitor -- --file "Файл обмена XLSX.xlsx" --headed
```

За один запуск проверяются первые 50 уникальных пар Caterpillar. Для последовательных пакетов используйте смещение:

```bash
npm run monitor -- --file "Файл обмена XLSX.xlsx" --limit 50 --offset 0 --headed
npm run monitor -- --file "Файл обмена XLSX.xlsx" --limit 50 --offset 50 --headed
```

Пауза между запросами по умолчанию составляет 1,5 секунды. Её можно увеличить параметром `--delay`, например `--delay 3000`.

В Windows PowerShell используйте `npm.cmd` вместо `npm`. Для проверки файла без обращения к сайтам:

```powershell
npm.cmd run monitor -- --file "Файл обмена XLSX.xlsx" --limit 3 --dry-run
```

Для первого рабочего пакета из 10 позиций Caterpillar:

```powershell
npm.cmd run monitor -- --file "Файл обмена XLSX.xlsx" --limit 10 --offset 0 --delay 3000 --headed
```

Полезные варианты:

```bash
npm run monitor -- 3687816 --sites impart
npm run monitor -- 3687816 --json
npm run monitor -- 3687816 --headed
```

История хранится в `.data/price-history.jsonl`. Ошибка хотя бы одного сайта даёт код завершения `2`, поэтому команду удобно запускать по расписанию и отслеживать сбои.

При длинном запуске оба сайта проверяются параллельно для каждой позиции. Результат каждой позиции немедленно добавляется в историю и вывод, поэтому уже собранные данные сохраняются при остановке компьютера или процесса.

## Проверка

```bash
npm test
npm run check
```

Тест браузера поднимает локальную страницу с формой поиска и проверяет весь путь: ввод артикула, отправку формы, извлечение предложений и выбор минимальной цены.

## Ограничения сайтов

Агент распознаёт CAPTCHA, открывает видимое окно для её прохождения и после проверки продолжает сбор. Если сайт изменит разметку поиска, адаптер соответствующего сайта находится в `src/sites.js`, а общая браузерная логика — в `src/site-monitor.js`.
